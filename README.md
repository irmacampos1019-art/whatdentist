# whatdentist.com.mx — Verified Dental Directory

## Overview
Static HTML website for whatdentist.com.mx — a verified dental directory for dental tourism in Mexico. Features dentist profiles, city pages, pricing tiers, and lead capture.

## SEO Features
- ✅ Real, crawlable HTML titles on every page
- ✅ Unique meta descriptions
- ✅ One clear H1 per page
- ✅ All content in rendered HTML (static — no JS rendering)
- ✅ Crawlable internal links
- ✅ Correct canonical URLs
- ✅ Working robots.txt and sitemap.xml
- ✅ Proper 404 page
- ✅ WebSite + Dentist structured data (JSON-LD)
- ✅ Fast page loading and mobile responsive
